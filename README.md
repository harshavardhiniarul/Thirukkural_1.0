# 📖 Thirukkural Finder

Thirukkural Finder is a simple web application that allows users to search for any Thirukkural by entering its number. The application displays the original Tamil Kural along with its Tamil explanation, Chapter , and Section .

## Features

- Search Thirukkural by number (1–1330)
- View the original Tamil Kural
- Display Tamil explanation
- Show Chapter and Section
- Responsive and user-friendly interface

## Tech Stack

- HTML
- CSS
- JavaScript
- Python Flask
- Thirukkural API
